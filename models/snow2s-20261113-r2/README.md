# Snow2S 新增数据重训版：20261113-r2

使用 9 个采集文件按接收时间 ±5 秒一对一配对，共 7,803 对样本，重新训练全部四组模型。
旧版的 4,611 对配对全部保留；新增 `20261113_0756.xlsx` 提供 3,153 对，
`20261111_2157.xlsx` 的完整文件尾部补入 39 对。

## 独立留出对比

测试段前留出 60 秒间隔，排除 4 对相邻样本。评估模型只用之前的 7,168 对记录训练，
最终交付模型则使用全部 7,803 对记录重训。

## 导出与接入

本目录的 `truetemp.c`、`truetemp.h`、`truetemp_snow2s_model_data.h` 构成 C 源码包。
编译库和调用方均定义 `TRUETEMP_SNOW2S`，链接 `libm`，十项输入接口保持兼容。
新模型保留紧凑节点格式，需配套使用支持该格式的运行时代码。

从 TrueTemp 仓库根目录运行：

```bash
make -C linux snow2s SNOW2S_MODEL_DIR=../models/snow2s-20261113-r2
./linux/truetemp_infer_snow2s 27 32.3 55.1 45.3 572 980 466 7.7 241 0
```

此组示例输出 `temperature=24.5000 humidity=34.1746`。27℃ 为合成输入，不能用此结果证明外推精度。
本机 C99 编译和 16,440 组 C/Python 输出核对通过，温度最大差约 0.000028℃。
26℃ 处仍直接切换，417 条接近上限工况的边界最大跳变约 2.367℃；详情见 `validation.json`。

## 复现

绝对温度及水汽压模型保存在 `models/snow2s-20261113-r2-base/`。
`base_training_command.json` 保存冻结输入目录和完整训练命令；基础训练日志位于
`build/snow2s-20261113-r2/base_training.log`。

在仓库根目录从基础模型生成新候选目录：

```bash
.venv/bin/python train_snow2s_hybrid.py \
  --base-dir models/snow2s-20261113-r2-base \
  --output-dir models/snow2s-20261113-r2-reproduced \
  --source-root build/snow2s-20261113-r2 \
  --heat-gate-max 4.5 --shrink-fraction 1.0
```

输出目录须不存在。训练参数、软件版本和源码校验值见 `model_2stage_metadata.json`。
