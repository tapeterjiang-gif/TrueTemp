## 验证结果

取新文件末尾 20%（369 对，北京时间 2026-11-14 20:11:56～22:00:21）验证，使用更早的 10,027 对训练，边界隔离 60 秒，隔离区排除 6 对。
对比基线为 `snow2s-20261114-trees200`，两版评估同一留出集。

| 指标 | 上一版 | 新验证模型 |
|---|---:|---:|
| 温度 MAE（℃） | 0.8153 | 0.0853 |
| 温度 P95 绝对误差（℃） | 1.0177 | 0.1833 |
| 温度最大绝对误差（℃） | 1.1191 | 0.7000 |
| 湿度 MAE（百分点） | 2.5432 | 0.7453 |
| 湿度 P95 绝对误差（百分点） | 3.1920 | 1.8191 |
| 湿度最大绝对误差（百分点） | 3.4725 | 2.1995 |

验证模型的原始温度上限为 27.0℃，留出集有 7 对触发上限外分支。
最终模型用全部 10,402 对重新训练，原始温度上限更新为 27.1℃，温差中位数 2.4℃。
上述留出指标属于单独训练的验证模型，不是最终全量模型的独立实机精度；单次采集末段验证不能代表跨环境表现。

## C 导出与精度核对

已生成 JSON 和 C 包，四组共 800 棵树、23,010 个节点，模型数组 185,680 字节（181.3 KiB）。宿主 C99 编译通过 `-O2 -Wall -Wextra -Werror`。

10,402 条真实输入和 201 条上限外探针共 10,603 组核对通过：将 Python 参考实现的策略常量转为 float32，与 C 常量保持同一精度后，最大温度差 0.00002312℃、湿度差 0.00005951 个百分点。

本次发现并保留记录的比较限制：27.1 无法用二进制单精度精确表示。若把输入转成 float32，却保留 Python 策略上限的 double 精度，7 条边界样本会选择不同分支，最大温差约 0.740℃。生产 C 的输入和常量同为 float32；本次在验证参考端统一常量精度，没有修改公共 Python 推理代码或 C 补偿策略。使用 Python 对照 C 时需应用同样的精度处理。边界直接切换仍存在，未做实机验证。
