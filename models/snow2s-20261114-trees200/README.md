# Snow2S 2026-11-14：200 树训练结果

沿用此前选定的四组模型各 200 棵树、±5 秒配对、4.5℃ 门限及 100% 少扣比例。

## 数据

- 使用 r2 冻结的 7,803 对训练记录，加上 `data/20261114_1134.xlsx` 新配对的 754 对，共 8,557 对；不重新读取或纳入其他 XLSX 后续追加内容。
- 新文件去重后 REF 905 条、DUT v4 2,004 条；每条最多配对一次。跨文件两侧时间戳无重复，必需输入与标签通过有限值及范围检查。
- 新文件参考温度 23.8～24.2℃，合并后 20.0～24.2℃。
- 全量训练后原始温度上限及温差中位数由数据重新计算，具体值见元数据；补偿策略不变。

## 留出验证

固定每组 200 棵树，不重新选参数。取新文件末尾 20%（151 对，2026-11-14 北京时间 13:52:33～14:29:02）作为验证集，训练使用此前 8,406 对，切分边界设置 60 秒隔离。旧模型和新训练的验证模型评估同一批样本。

| 指标 | 旧 200 树模型 | 新验证模型 |
|---|---:|---:|
| 温度 MAE（℃） | 0.2113 | 0.0859 |
| 温度 P95 绝对误差（℃） | 0.3000 | 0.2161 |
| 湿度 MAE（百分点） | 0.3666 | 0.1513 |
| 湿度 P95 绝对误差（百分点） | 0.6118 | 0.3585 |

验证完成后，本目录最终模型用全部 8,557 对重新训练。上述留出指标属于单独训练的验证模型，不是最终模型在独立测试集上的成绩。单次采集末段验证不能证明跨环境精度，未做新的实机验证；留出样本未触发超出原始温度上限的回退分支。
