# Snow2S 树数量与精度体积对比：200 树候选

结论：建议试用每组 200 棵树（四组共 800 棵）的独立候选。模型数组由 451.6 KiB 降到 181.7 KiB，减少 59.8%；头文件由 1.272 MB 降到 0.509 MB，减少 60.0%。原 500 树版完整保留，本候选尚未同步到 Snow2SApp。

## 方法

- 固定 r2 的 9 个文件、7,803 对样本及 ±5 秒配对；直接使用冻结的 training_pairs.csv，不读取后续追加数据。
- 每组分别对比 100、200、300、500 棵树，学习率 0.05、最多 15 叶子、深度 5 等参数不变；不量化、不改变输入特征或补偿规则。
- 每个评估时段独立按对应树数量重新训练四组模型，不用全量训练模型评估留出段，不做 early stopping。
- 复用最近文件末尾 631 对留出样本，训练 7,168 对，间隔 60 秒；500 树基线完整复现上次指标。
- 在这 7,168 对较早数据中增加三个扩展训练窗口的时间切分，每段测试 1,792 对，均排除测试前 60 秒内训练样本。
- 最终候选取全量 r2 每组模型的前 200 棵树；已核实与全量数据独立训练 200 棵的四组树逐节点完全相同。
- 宿主 C99 实际编译，通过 sizeof 测量节点与树根索引总大小，未将源码文本或整个动态库大小当作模型数组大小。

### 选择 200 的依据

本实验预先采用相对 500 树的工程筛选容差：每个时段及合并结果的温度 MAE 增量 ≤0.02℃、温度 P95 增量 ≤0.05℃、湿度 MAE 增量 ≤0.10 个百分点、湿度 P95 增量 ≤0.20 个百分点。这是本次筛选规则，不是用户确认的产品精度规格，也不是统计等效性检验。

- 200 和 300 均通过，选择体积较小的 200。200 树在三个较早时段的湿度 MAE 最大增加 0.066 个百分点，温度 MAE 均未增加。
- 100 树在时段 3 的湿度 MAE 增加 0.123、P95 增加 0.238 个百分点，超出上述容差，暂不优先选用。
- 最近留出段 200 树温度 MAE 改善 0.027℃，湿度 MAE 增加 0.026 个百分点；最近段的温湿度 P95 均改善。

## C 导出与分支核对

- 全部四种树数量的 C99 编译通过（-O2 -Wall -Wextra -Werror）。200 树版核对 16,440 组输入，其中 7,803 组真实输入、8,637 组合成探针。
- C/Python 最大差：温度 0.00002851℃，湿度 0.00009414 个百分点。
- 7,803 组工况将原始温度替换为 27℃作分支探针：200 与 500 树的少扣门限判断切换次数为 0；温度输出差平均 0.016℃、P95 0.062℃、最大 0.180℃。这些是模型间差异，不是真实精度。
- 真实训练输入回放的两版温度输出差平均 0.016℃、最大 0.287℃；湿度差平均 0.075、最大 0.943 个百分点。整体接近不代表每个样本完全相同。
- 保留门限 4.5℃、少扣比例 100%、基准 2.5℃和原始温度上限 26℃。已有分支切换不连续仍存在：417 组近边界探针最大跳变 2.368℃，500 树原版为 2.367℃。本次只减少树数量，未修改该策略。

## 限制

- 最近留出段已被反复用于方案比较，因此是选型验证，不能当作新的盲测；尚无独立实机验证。
- 参考温度仍只有 20.0～22.9℃，没有 24～25℃参考样本；合成高温输入不能证明高温外推精度。
- 较早时段 1 有 1,077 对数据超过该折训练的原始温度上限，因此覆盖了折内回退分支；它不能替代最终 26℃以上场景的实测。
- 未做性能或目标板 RAM 占用测量；数组为 static const，只读存储大小与运行时总内存并非同一指标。
