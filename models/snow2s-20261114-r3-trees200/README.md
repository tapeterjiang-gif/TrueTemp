# Snow2S 2026-11-14 第三批 200 树模型

使用上一版冻结的 10,402 对样本和 `data/20261114_2232.xlsx` 新增的 4,956 对，共 15,358 对。新文件按接收时间 ±5 秒唯一配对，去重后 REF 5,855 条、DUT v4 13,582 条。全量参考温度范围由 20.0～24.7℃ 扩至 20.0～25.0℃。

沿用四组各 200 棵树、4.5℃ 门限和 100% 少扣比例。全量模型的原始温度上限为 27.1℃，温差中位数为 2.3℃。

## 时间留出验证

取新文件末尾 992 对样本（北京时间 2026-11-15 16:14:41～20:35:07），使用更早的 14,361 对训练验证模型，边界隔离 60 秒，排除 5 对。基线为 `snow2s-20261114-r2-trees200`。

| 指标 | 上一版 | 新验证模型 |
|---|---:|---:|
| 温度 MAE（℃） | 0.3985 | 0.2481 |
| 温度 P95 绝对误差（℃） | 0.8587 | 0.4541 |
| 湿度 MAE（百分点） | 1.2403 | 0.8321 |
| 湿度 P95 绝对误差（百分点） | 2.5674 | 2.3234 |

留出集未触发原始温度上限外分支。交付模型在验证后用全量样本重训，表中成绩来自单独训练的验证模型。详见 `evaluation.json` 和 `holdout_predictions.csv`。

## 导出与复现

JSON 与 C 模型共 800 棵树、23,012 个节点。C99 宿主编译和 15,561 组 C/Python 对照通过，其中 203 组为上限外探针。策略常量统一为 float32 后，温度和湿度最大差为 0.000020℃ 和 0.000053 个百分点。若保留 Python 的 double 上限并输入 float32 数据，27.1℃ 处有 7 个样本会选到不同分支，温度最大差为 0.833℃。详见 `validation.json`。

从仓库根目录运行。已有验证通过的输出受脚本保护，复现时可在脚本中指定新的输出目录。

```sh
DYLD_LIBRARY_PATH=/opt/homebrew/opt/llvm/lib OMP_NUM_THREADS=2 .venv/bin/python -B build/snow2s-20261114-r3-trees200/train.py
```

本版已在 TrueTemp 导出，待同步至 Snow2SApp 并做实机验证。
